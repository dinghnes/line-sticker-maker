# 🎨 LINE Sticker Maker Pro Creator (LINE 貼圖與表情貼旗艦創作者工具)

[![React](https://img.shields.io/badge/React-18-blue.svg)](https://react.dev/)

專為 **LINE 貼圖 (Stickers)** 與 **LINE 表情貼 (Emojis)** 創作者打造的頂級全流程生產工具。全方位滿足 **LINE Creators Market 最新審查規範**：

1. **🔍 跨分類智慧情境關鍵字即時搜尋 ＋ 熱門靈感標籤 (v3.6 新增)**：
   - 搜尋框支援跨全部分類（750+ 詞彙）模糊比對，如輸入「中秋」、「烤肉」、「想睡」、「開會」、「請假」，一秒跨庫找到精準語句！
   - 提供「🌕 中秋節慶」、「🍖 烤肉聚餐」、「💼 開會工作」、「😴 想睡耍廢」等熱門情境快選按鈕。
   - 支援「一鍵填入前 12 個」或點選單詞直接帶入貼圖編輯格。
   - 12 格輸入框全面支援「全庫 750+ 詞彙自動完成下拉選單 (Datalist Autocomplete)」，邊打邊選超省力！
2. **🌕 中秋團圓烤肉專屬套裝 ＋ 專屬 Midjourney 動作字典 (v3.6 新增)**：
   - 新增「🌕 中秋團圓烤肉」12 格精選一鍵套用套裝（中秋快樂、月圓人團圓、烤肉啦、吃月餅、賞月去、柚子帽、分你吃、超香的、乾杯、吃太飽、連假萬歲、團圓囉）。
   - 針對中秋系列詞彙深度定制 Midjourney 神態動作字典（手捧月餅、戴柚子帽、金黃滿月、烤肉串、小烤爐飄炊煙、全家團圓）。
3. **🎨 17 種繪畫風格 ＋ 自訂畫風功能 (v3.5 擴充)**：
   - 🗡️ **經典東方武俠風**、💥 **熱血硬派港漫風**、🐱 **搞怪白爛手繪風**、🍬 **三麗鷗粉嫩糖果風**、✏️ **極簡黑白線條風**、📚 **溫暖童話繪本風**、🧸 **軟萌黏土手作風**、🎁 **潮玩盲盒公仔風**、✨ **80年代復古少女漫**、🇯🇵 **日系動漫風** 等共 17 種風格。
   - ✏️ **自訂自填風格 (Custom)**：可隨意填寫自訂畫風關鍵字，無縫融入 Midjourney Prompt！
4. **👑 官方張數拼裝器**：
   - 支援「**一鍵精選 8 張正式送審包**」，直接符合官方送審門檻！
   - 支援「**+ 追加第 2 批網格圖**」，12 + 12 = 24 張無縫串聯，直接產出官方最熱門的「**24 張正式送審包**」！
5. **📱 LINE 手機聊天室真實情境模擬器**：
   - 內建高擬真手機聊天視窗，支援「**LINE 經典綠/藍**」與「**暗黑模式**」，即時驗證對話氣泡與字體易讀性！
6. **🛡️ LINE 官方 10px 透明安全邊距防退件保證**。
7. **🛡️ 獨家外圍泛洪防穿孔去背 (Flood Fill)**。

## 🌟 創作者必看：LINE 官方送審規範速查

| 規格項目 | 🟢 LINE 一般靜態貼圖 (Stickers) | 🟣 LINE 一般表情貼 (Emojis) |
| :--- | :--- | :--- |
| **官方送審張數限制** | **只能選 8 / 16 / 24 / 32 / 40 張** | **8 ～ 40 張皆可**（任意整數張） |
| **本工具解決方案** | 1. 點擊「一鍵精選前 8 張」→ 產出 **8 張送審包**<br>2. 點擊「+追加第2批」→ 產出 **24 張送審包** | 12 格切圖直接符合 8~40 張規定，為**正式送審包** |
| **主要封面圖 (main.png)** | **強制需要**（240 × 240 px，系統自動等比產出） | ❌ **不需要**（官方規定無此欄位） |
| **聊天室標籤圖 (tab.png)** | **強制需要**（96 × 74 px，系統自動等比產出） | **強制需要**（96 × 74 px，系統自動等比產出） |
| **圖檔編號格式** | `01.png` ～ `24.png`（兩位數編號） | `001.png` ～ `040.png`（三位數編號） |
| **透明安全邊距** | **強制約 10px**（系統自動防退件縮放） | **強制約 10px**（系統自動防退件縮放） |
